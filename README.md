Учебный проект на Python — Telegram-бот с инструментами для работы в Linux и изучения сетевой разведки.

В проекте развиваются команды для работы с Nmap, WHOIS, DNS и другими инструментами. Цель — объединить полезные утилиты в одном интерфейсе и разобраться в их работе.
